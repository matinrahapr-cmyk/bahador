# فروشگاه آجر جهان‌نما — نسخه آماده GitHub Pages

این پروژه با Next.js و TypeScript ساخته شده و به‌صورت خودکار روی GitHub Pages منتشر می‌شود.

## ساختار نهایی محصولات

- آجر نما
  - آجر نسوز
    - آجر انگلیسی
    - آجر شاموتی
    - ابعاد آجر نسوز: ۷×۳۱، ۸×۴۰، ۱۰×۶۰، ۲۰×۸۰، ۱۲×۱۰۰
  - آجر سفید، طوسی، قهوه‌ای
  - آجر مشکی
    - آجر شومینه، کرکره‌ای، تایل
  - آجر قزاقی، دکوراتیو، رستیک، لعابی، سنتی، رسی
- آجر کوره
- آجر کف
- آجر معمولی
- مصالح جانبی

## انتشار روی GitHub

1. یک Repository جدید بسازید.
2. تمام محتویات همین پوشه را در ریشه Repository آپلود کنید؛ خود پوشه را به‌صورت یک پوشه اضافی آپلود نکنید.
3. شاخه اصلی باید `main` باشد.
4. در GitHub وارد `Settings > Pages` شوید.
5. در بخش **Build and deployment**، گزینه Source را روی **GitHub Actions** قرار دهید.
6. وارد تب `Actions` شوید و منتظر بمانید اجرای `Deploy Next.js to GitHub Pages` سبز شود.
7. آدرس سایت در `Settings > Pages` نمایش داده می‌شود.

## اجرای محلی

```powershell
npm.cmd install
npm.cmd run dev
```

سپس باز کنید: `http://localhost:3000`

> فرم‌ها و قیمت‌ها در این نسخه نمایشی هستند و به دیتابیس متصل نیستند.
