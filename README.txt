نسخه مستقل HTML فروشگاه آجر نمای نسوز پایا

روش اجرا:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) فایل index.html را با مرورگر باز کنید.

این نسخه به نصب Node.js یا اجرای دستور خاصی نیاز ندارد و تصاویر، CSS و JavaScript را به‌صورت محلی در اختیار دارد.

نکته: فرم استعلام در این نسخه نمایشی است و برای ارسال واقعی اطلاعات باید به سرویس بک‌اند، ایمیل یا CRM متصل شود.
