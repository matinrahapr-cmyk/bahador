# وب‌سایت آجر نمای نسوز پایا

این پروژه یک وب‌سایت مستقل HTML/CSS/JavaScript است و برای اجرا یا انتشار به Node.js و نصب پکیج نیاز ندارد.

## مشاهده روی کامپیوتر

فایل `index.html` را با مرورگر باز کنید.

## انتشار در GitHub Pages

1. یک Repository جدید در GitHub بسازید.
2. همه فایل‌ها و پوشه‌های این پروژه را در ریشه Repository آپلود کنید؛ فایل `index.html` باید در صفحه اول مخزن دیده شود.
3. وارد `Settings` و سپس `Pages` شوید.
4. در بخش `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کنید.
5. Branch را روی `main` و Folder را روی `/ (root)` بگذارید و `Save` را بزنید.
6. چند دقیقه بعد لینک عمومی سایت در همان صفحه نمایش داده می‌شود.
