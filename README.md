# سایت آجر نمای نسوز پایا

نسخه استاتیک آماده انتشار با GitHub Pages.

## انتشار در GitHub Pages

1. در GitHub یک Repository جدید بسازید.
2. تمام محتویات این پوشه را در ریشه Repository آپلود کنید؛ خود پوشه را به‌صورت ZIP آپلود نکنید.
3. وارد `Settings` و سپس `Pages` شوید.
4. در بخش `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کنید.
5. Branch را روی `main` و Folder را روی `/ (root)` قرار دهید و `Save` را بزنید.
6. پس از چند دقیقه لینک سایت در همان صفحه نمایش داده می‌شود.

فایل `index.html` باید مستقیماً در صفحه اصلی Repository دیده شود.

## اجرای محلی

فایل `index.html` را در مرورگر باز کنید. برای پیش‌نمایش دقیق‌تر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## ساختار

- `index.html`: صفحه اصلی
- `styles.css`: طراحی و حالت واکنش‌گرا
- `script.js`: منو، محاسبه‌گر و تعاملات
- `assets/`: لوگو و تصاویر سایت

فرم استعلام در این نسخه نمایشی است و برای دریافت واقعی اطلاعات باید به بک‌اند یا سرویس فرم متصل شود.
